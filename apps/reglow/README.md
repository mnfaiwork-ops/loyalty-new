# Loyalty Reglow

App Laravel 12 untuk brand Reglow (`APP_BRAND=reglow`). Logika bersama ada di `packages/core`.

Jangan edit file di folder ini langsung. Ubah di `apps/amura`, lalu jalankan `bash scripts/sync-reglow.sh` dari root repo.

Panduan lengkap: [`docs/HANDOVER.md`](../../docs/HANDOVER.md) dan [`docs/DEPLOY.md`](../../docs/DEPLOY.md).
